Agent index for GitHub Pages deployment

AI / MCP-ready entry point for the App Control for Business bundle

GitHub Pages cannot host a live MCP server by itself, so the best static pattern is a dedicated agent landing page plus a machine-readable manifest. This gives coding agents one canonical URL for discovery, then points them at llms.txt, the docs index, and the full set of reference pages.

Canonical site: /appControlBusiness/ Agent page: /ai/ Machine file: resources.json
Best practice: start with llms.txt, then hop to the manifest or docs index.
What this gives agents A single path that exposes the documentation graph, not just the homepage.
What it is not A live MCP transport. For that, host a real MCP server elsewhere and point it at these static assets.
Why this is best on Pages It is cacheable, indexable, and survives GitHub Pages deployment without extra infrastructure.

Recommended agent flow

For coding agents, this is the shortest reliable path into the bundle:

  1. Open llms.txt for the high-level map.
  2. Use docs/index.md to jump to the relevant document family.
  3. Use the sitemap.xml or resources.json for machine-readable discovery.
  4. Read the part, rule-option, or file-rule page you actually need instead of scraping the whole bundle.

High-value paths

These are the pages an LLM will usually want first.

  • /llms.txt
  • /docs/index.md
  • /docs/log.md
  • /OKF-SPEC.md
  • /README.md

Machine-readable manifest

The companion JSON file is easier for tools to parse than HTML navigation and now advertises the generated assets too.

{
  "baseUrl": "https://anubhavg-icpl.github.io/appControlBusiness/",
  "agentIndex": "https://anubhavg-icpl.github.io/appControlBusiness/ai/",
  "llmsTxt": "https://anubhavg-icpl.github.io/appControlBusiness/llms.txt",

Available agent assets

These are now generated from the Markdown corpus and deployed as static files.

  • search-index.json for full-text lookup across the 51 Markdown documents.
  • llms-full.txt as a single offline bundle for agent ingestion.
  • frontmatter/index.json plus per-page JSON exports under /ai/frontmatter/.
  • updates.json and atom.xml for machine-readable change detection.

Deployment note

This page is static and deploys cleanly through the existing GitHub Pages workflow. If you later want a real MCP server, deploy it on a separate runtime such as Cloudflare Workers, Fly.io, Render, or Vercel, then have that server expose or proxy these same resource URLs.
